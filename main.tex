  \item \proj{\href{https://pilotspace.github.io/lunaris/}{Lunaris} \& Helios}{retrieval pipeline and agent harness}
  Lunaris is ingest, extraction, embeddings, vector search and reranking behind one API, recalling across 100K documents per scope in 19--22\,ms at the median. Its quality is gated rather than asserted: CI scores LongMemEval-S evidence recall judge-free, on both operating points, and fails the build when recall drops past tolerance or the retrieval config moves under the baseline. I wrote that gate after finding its predecessor had never once run --- 200 of 200 recorded executions were startup failures, so nothing had been gated at all. Helios consumes it: 12 provider backends, a native MCP client and server, and a circuit breaker on every outbound call.
  \stack{Rust · Tokio · llama.cpp embeddings · MCP · Wasmtime · npm / PyPI / crates.io}

  \item \proj{\href{https://pilotspace.github.io/moon/}{Moon}}{Redis-compatible in-memory store, written from scratch}
  Existing Redis clients connect unchanged: RESP2/RESP3, 250+ commands, and native vector, BM25 and graph search under MVCC. Thirty releases to v0.8.9, measuring 1.62\texttimes{} on GET and 1.32\texttimes{} on SET against Redis 7.0 with 8--22\% less memory per key --- published alongside the command families where it loses.
  \stack{Rust · Tokio · io\_uring · crates.io · PyPI}

  \item \proj{\href{https://pilotspace.github.io/ADD/}{ADD}}{the method behind the projects above}
  An agent writes most of my code, so I made the trust explicit: the contract is frozen and hashed before any code exists, the failing test is committed before the fix, and a build is accepted on a receipt binding the passing run to the files that produced it --- never on a diff that reads well. I published a six-milestone benchmark of the method, then retracted my own headline claim after finding a defect in my own meter; the corrected report has it costing 1.7\texttimes{} the cheaper alternative on a workload that could not tell them apart. Shipped as \texttt{@pilotspace/add} and \texttt{pilotspace-add} at 3.6.0.
\end{itemize}
